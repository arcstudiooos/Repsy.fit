# Landing page design direction

Chosen with the ui-ux-pro-max design-intelligence tool
(https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), styles "Exaggerated Minimalism" and
"Editorial Grid / Magazine". The tool's palette suggestion (blue + glassmorphism) was rejected
because `CLAUDE.md` fixes the Repsy colours. Everything below uses existing tokens only.

**Tone:** a sports-magazine training log. It should feel confident, plain-spoken and
type-led, and must not look like a generic AI template.

**Signature element:** the training-log band under the hero. It shows real set notation
(`Back Squat 4 × 6 · Rest 120s`), written exactly the way the Manual Planner saves it.

## Rules

| Area | Rule |
|---|---|
| Type | Oversized Barlow Condensed headlines (`.l-display`, `.l-h2`) with Inter body. Each section opens with a numbered kicker (`01 — The problem`). |
| Colour | `#141414` and cream `#FAF7F2`, with one accent, orange `#FF4A1F`. Teal `#0E7C6B` is for data (charts) only. No gradient blobs, glows or glass. |
| Structure | Hard 2px rules and big orange numerals instead of icon cards. Generous vertical space (`py-20 md:py-28`). |
| Links | "Try it in the app" is an uppercase underlined link with an arrow, never a pill button. |
| Avoid | Emoji icons, stock "trusted by" strips, fake metrics, centered everything, three identical icon cards, purple gradients. |
